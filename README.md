# Ebola Surveillance, Preparedness and Risk Assessment Dashboard Cameroon

Prototype Streamlit dashboard for exploring outbreak surveillance records,
reviewing data-quality limitations, viewing Cameroon health-district geography
and organising preparedness indicators.

**Status:** Prototype only. It does NOT predict Ebola introduction or
transmission in Cameroon. No model has been trained or validated, and there are
no confirmed Cameroon case data or validated district-level risk scores.
The scenario explorer is experimental and uncalibrated.

## Run locally
pip install -r requirements.txt
streamlit run app.py
